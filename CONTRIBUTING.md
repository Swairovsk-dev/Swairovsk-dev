# Como contribuir

Este repositório mantém o README do perfil de Swairovsk-dev.

## Sugestões e melhorias

- Confira se os links do perfil abrem corretamente.
- Sugira melhorias de clareza, acessibilidade ou documentação.
- Explique no pull request o que mudou e como verificou a alteração.

## Como enviar uma alteração

1. Faça um fork deste repositório.
2. Crie uma branch para sua melhoria.
3. Edite o arquivo e salve com um commit.
4. Abra um pull request para o repositório original.
5. Explique o que mudou e confira a prévia do Markdown.

## Trabalhando em dupla

1. Escolham uma melhoria pequena e trabalhem juntos no texto ou código.
2. Registrem os dois autores no commit com o trailer `Co-authored-by`, usando o e-mail associado ao GitHub de cada participante (pode ser o endereço noreply).
3. Confiram o diff e os créditos antes de fazer o merge.

Não incluam senhas, tokens ou outras informações privadas nos arquivos.
